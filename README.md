# allegro-ar

Testes de viabilidade do Rótulo Vivo Allegro (Vinícola Borgo): realidade aumentada no navegador com MindAR.

- `index.html`: lista dos testes
- `t0/`: câmera e reconhecimento com o alvo de exemplo do MindAR
- `alvo.html`: alvo de exemplo para abrir em outra tela
- `assets/lib/`: A-Frame 1.5.0 e MindAR 1.2.5 hospedados aqui (sem depender de CDN)
- `assets/targets/`: alvos compilados (`.mind`)

Publicado via GitHub Pages (branch `main`, pasta raiz).
